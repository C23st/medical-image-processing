# 医学图像处理期末大作业 — 开发方案

> 技术栈: Python 3.10 + PySide6 + VTK | 本文档记录整体规划、架构、里程碑与当前进度

## 1. 项目概述

### 1.1 目标

开发一个**医学图像处理软件**（仿 3D Slicer 风格），实现 DICOM 医学图像的打开、解读、显示、增强、分割与三维重建，并最终打包为可执行的 exe。

### 1.2 需求清单（对应评分点）

| # | 需求 | 交付形态 | 状态 |
|---|------|---------|------|
| 1 | 软件界面 + exe/安装包 | 桌面应用，功能分区清晰（菜单栏/工具栏/图像区/信息区） | 界面 ✅ / 打包 ⏳ |
| 2 | DICOM 打开/解读/显示 | 元数据解析、多序列、窗宽窗位、三平面显示 | ✅ |
| 3 | 图像分割 + 显示结果 | 阈值/Otsu/区域生长 + 彩色标签叠加 + 真值 Dice 对比 | ✅ |
| 4 | 图像增强 | 灰度变换/直方图/空间滤波/频域（11 种方法） | ✅ |
| 5 | 三维重建 + 显示 | 面绘制 (Marching Cubes) + 体绘制 (Ray Casting) | ✅ |
| 6 | 三维视图显示二维切片位置 | 正交切平面 (带纹理) + 随翻层实时联动 | ✅ |

## 3. 总体架构

```

├─────────────────────────────────────────────┤
│  业务层  视图联动、数据管理、交互状态机          │
├─────────────────────────────────────────────┤
│  算法层  enhance / segment / (重建) 纯函数     │
├─────────────────────────────────────────────┤

```


## 4. 界面设计（仿 3D Slicer）

- **菜单栏**: 文件（打开 DICOM 文件夹 / 最近打开 / 退出）、帮助（关于）
- **中央四视图**: Axial / Coronal / Sagittal + 3D（四视图联动）
- **每个视图左上角图标工具栏**（悬停显示说明）：
  - 切片视图: `↺`复位 · `✛`十字准星 · `3D`(在3D中显示本视图切平面)
  - 3D 视图: `↺`复位视角 · `前 后 右 左 上 下` 标准视角
- **左侧**: 数据树（病人-序列，双击切换）
- **右侧**: 参数面板（显示 / 增强 / 分割 / 三维重建 页签）
- **底部**: 信息区（病人/模态/尺寸/切片/位置/体素值/WW-WL）+ 状态栏
- **每个切片视图底部**: 滑动条（快速翻层）

## 5. 功能模块设计

### 5.1 DICOM 模块（P2 ✅）
- 递归扫描目录，按 SeriesInstanceUID 分组，SOPInstanceUID 去重
- 单帧序列按 ImagePositionPatient 排序；多帧 SEG 按帧位置
- RescaleSlope/Intercept 换算 HU；WindowWidth/Center 读入窗位
- ImageOrientationPatient → 方向余弦矩阵（`index_to_ras` 输出 RAS 坐标）

### 5.2 显示模块（P1/P2 ✅）
- numpy 切片 + vtkImageActor，窗宽窗位在显示层映射
- 三正交视图 + 标签叠加（RGBA 半透明）
- 悬停/拾取/十字联动/缩放/平移

### 5.3 图像增强（P3 ✅）
| 类别 | 方法 |
|------|------|
| 灰度变换 | 线性拉伸(百分位截断) / 对数 / 伽马 |
| 直方图 | 全局均衡 / CLAHE |
| 空间滤波 | 均值 / 中值 / 高斯 / 锐化 |
| 频率域 | 频域滤波(FFT 低通/高通/带通) |
| 保边去噪 | 双边滤波 |

- 归一化类 → 数据变为 [0,255]，窗位自动 255/128；滤波类 → 保持 HU，窗位沿用原始值
- **链式叠加**：增强基于当前结果继续处理，可组合多种增强；支持**撤回上一步**与「恢复原图」
- 逐切片 2D 方法采用**全卷全局归一化/缩放**，避免冠状/矢状面出现层间条纹

### 5.4 图像分割（P4 ✅）
- 阈值分割（HU 可调）、Otsu 自动阈值、区域生长（种子+容差，6 邻域连通）
- 结果半透明红色叠加；与自带 SEG 胰腺真值计算 **Dice**（位置映射 `match_seg_to_ct`）
- 分割基于原始 CT 数据（与显示是否增强无关）

### 5.5 三维重建（P5 ✅）
- 面绘制：vtkFlyingEdges3D（Marching Cubes），阈值预设 骨300/软组织40/皮肤-150/掩膜0.5
- 体绘制：vtkSmartVolumeMapper（Ray Casting，自动 GPU/CPU），不透明度可调
- 3D 视图交互：左键旋转、滚轮缩放、中键平移；Z 轴向上
- **基于原始数据重建**（与分割一致）：增强只影响显示，不影响重建，阈值保持 HU 语义

### 5.6 二维切片在三维中的定位（P6 ✅）
- 3D 视图显示三个正交切平面（Axial/Coronal/Sagittal），**带实际 CT 图像纹理 + 红色分割叠加 + 半透明**
- 平面位置按 方向矩阵+origin+spacing 计算（`index_to_world`），随切片翻层/十字联动实时更新
- 各切片视图左上角 `3D` 按钮独立控制对应切平面显示

## 8. 风险与注意事项

- **打包体积**：PyInstaller + VTK/PySide6 生成的 exe 数百 MB 属正常
- **性能**：512×512×240 全卷滤波/分割需数秒，期间有等待光标
- **Dice 偏低**：CT 上简单方法难以单独抠出胰腺（软组织灰度接近），属正常现象，报告中可说明
- **视觉验证**：部分渲染效果需在带显示器/GPU 的桌面会话确认
- **版本管理**：git 仓库本地管理，每阶段一个提交，可随时回退
