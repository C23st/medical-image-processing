# 医学图像处理期末大作业 — 开发方案

> 技术栈: Python 3.10 + PySide6 + VTK | 本文档记录整体规划、架构、里程碑与当前进度

## 1. 项目概述

### 1.1 目标

开发一个**医学图像处理软件**（仿 3D Slicer 风格），实现 DICOM 医学图像的打开、解读、显示、增强、分割与三维重建，并最终打包为可执行的 exe。

### 1.2 需求清单（对应评分点）

| # | 需求 | 交付形态 | 状态 |
|---|------|---------|------|
| 1 | 软件界面 + exe/安装包 | 桌面应用，功能分区清晰（菜单栏/工具栏/图像区/信息区） | 界面 ✅ / 打包 ⏳ |
| 2 | DICOM 打开/解读/显示 | 元数据解析、多序列、窗宽窗位、三平面显示 | ✅ |
| 3 | 图像分割 + 显示结果 | 阈值/Otsu/区域生长 + 彩色标签叠加 + 真值 Dice 对比 | ✅ |
| 4 | 图像增强 | 灰度变换/直方图/空间滤波（9 种方法） | ✅ |
| 5 | 三维重建 + 显示 | 面绘制 (Marching Cubes) + 体绘制 (Ray Casting) | ⏳ P5 |
| 6 | 三维视图显示二维切片位置 | 十字定位/切平面联动 | ⏳ P6 |

## 2. 技术选型

| 类别 | 选择 | 说明 |
|------|------|------|
| 语言 | Python 3.10 | 与 Anaconda 环境一致 |
| GUI | PySide6 6.11 | Qt 6，3D Slicer 同族 |
| 3D/可视化 | VTK 9.7 | 重建、切片、三维视图 |

## 3. 总体架构

```

│  UI 层  PySide6（主窗口/四视图/面板/信息区）    │
├─────────────────────────────────────────────┤
│  业务层  视图联动、数据管理、交互状态机          │
├─────────────────────────────────────────────┤
│  算法层  enhance / segment / (重建) 纯函数     │
├─────────────────────────────────────────────┤
│  数据层  VolumeData 封装、dicom_loader         │
└─────────────────────────────────────────────┘
```

**目录结构**：
```
app/
├── main_window.py       # 主窗口（菜单/工具栏/停靠区/信号接线）

│   ├── volume.py        # VolumeData: 数据+spacing+origin+direction, index_to_ras
│   ├── dicom_loader.py  # DICOM 序列加载（去重/多帧/窗位/方向矩阵）

│   ├── enhance.py       # 9 种增强算法
│   └── segment.py       # 阈值/Otsu/区域生长/Dice/真值映射
├── views/
│   ├── slice_view.py    # 二维切片视图（numpy+vtkImageActor, 交互）
│   ├── view3d.py        # 三维视图（P5 填充）
│   └── four_view.py     # 四视图布局
└── widgets/
    ├── data_tree.py     # 数据树
    ├── params_panel.py  # 参数面板（显示/增强/分割/重建）
    └── info_bar.py      # 底部信息区
```

## 4. 界面设计（仿 3D Slicer）

- **菜单栏**: 文件 / 视图(重置视图、十字准星) / 分割 / 增强 / 三维重建 / 帮助
- **工具栏**: 打开、十字准星开关（其余为占位）
- **中央四视图**: Axial / Coronal / Sagittal + 3D（四视图联动）
- **左侧**: 数据树（病人-序列，双击切换）
- **右侧**: 参数面板（显示 / 增强 / 分割 / 三维重建 页签）
- **底部**: 信息区（病人/模态/尺寸/切片/位置/体素值/WW-WL）+ 状态栏

| 手势 | 功能 |
|------|------|
| 滚轮 | 翻层（只当前视图） |
| Ctrl + 滚轮 | 放大/缩小（平行投影） |

## 5. 功能模块设计

### 5.1 DICOM 模块（P2 ✅）
- 递归扫描目录，按 SeriesInstanceUID 分组，SOPInstanceUID 去重
- 单帧序列按 ImagePositionPatient 排序；多帧 SEG 按帧位置
- RescaleSlope/Intercept 换算 HU；WindowWidth/Center 读入窗位
- ImageOrientationPatient → 方向余弦矩阵（`index_to_ras` 输出 RAS 坐标）

### 5.2 显示模块（P1/P2 ✅）
- numpy 切片 + vtkImageActor，窗宽窗位在显示层映射
- 三正交视图 + 标签叠加（RGBA 半透明）
- 悬停/拾取/十字联动/缩放/平移

### 5.3 图像增强（P3 ✅）
| 类别 | 方法 |
|------|------|
| 灰度变换 | 线性拉伸(百分位截断) / 对数 / 伽马 |
| 直方图 | 全局均衡 / CLAHE |
| 空间滤波 | 均值 / 中值 / 高斯 / 锐化 |

- 归一化类 → 数据变为 [0,255]，窗位自动 255/128
- 滤波类 → 保持 HU，窗位沿用原始值

### 5.4 图像分割（P4 ✅）
- 阈值分割（HU 可调）、Otsu 自动阈值、区域生长（种子+容差，6 邻域连通）
- 结果半透明红色叠加；与自带 SEG 胰腺真值计算 **Dice**（位置映射 `match_seg_to_ct`）
- 分割基于原始 CT 数据（与显示是否增强无关）

### 5.5 三维重建（P5 ⏳ 规划）
- 面绘制：Marching Cubes（等值面，适合骨骼/皮肤）
- 体绘制：Ray Casting（适合软组织）
- 交互：旋转/缩放/平移 + 颜色透明度

### 5.6 二维切片在三维中的定位（P6 ⏳ 规划）
- 在 3D 视图中显示三个正交切平面的位置
- 基于方向矩阵 + `index_to_ras`（数据基础已具备）

## 8. 风险与注意事项

- **打包体积**：PyInstaller + VTK/PySide6 生成的 exe 数百 MB 属正常
- **性能**：512×512×240 全卷滤波/分割需数秒，期间有等待光标
- **Dice 偏低**：CT 上简单方法难以单独抠出胰腺（软组织灰度接近），属正常现象，报告中可说明
- **视觉验证**：部分渲染效果需在带显示器/GPU 的桌面会话确认
- **版本管理**：git 仓库本地管理，每阶段一个提交，可随时回退
