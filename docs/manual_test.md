# 手动测试指南 (v2) — 覆盖全部功能

> 适用版本: master `d45e2dc` 之后（含 DICOM 显示 / 十字准星联动 / 增强 / 分割 / 左键禁用）

## 0. 准备

1. 启动: 双击 `run.bat`（或 `D:\Anaconda_Envs\medimg\python.exe main.py`）
2. 菜单「文件 → 打开 DICOM 文件夹」→ 选 `test_data\PANCREAS_0001`（也可选 `test_data` 一次加载两个病人）
3. 左侧数据树出现序列，双击「序列: Pancreas」加载 CT
4. 确认三个切片视图显示腹部 CT（Axial 119/239、Coronal/Sagittal 255/511）

## 一、界面布局与基本视图操作

### 布局
- **菜单栏**: 文件 / 分割 / 增强 / 三维重建 / 帮助
- **工具栏**: 「打开」（其余按钮为占位，功能在右侧面板）
- **中央四视图**: Axial(左上) / Coronal(右上) / Sagittal(左下) / 3D(右下)
- **每个视图左上角有图标工具栏**（悬停显示文字说明）：
  - 切片视图: `↺`复位 · `✛`十字准星 · `▦`切片平面
  - 3D 视图: `↺`复位视角 · `前 后 右 左 上 下` 标准视角 · `▦`切片平面
- **左侧数据树**: 病人-序列，双击切换
- **右侧参数面板**: 显示 / 增强 / 分割 / 三维重建 四个页签
- **底部信息区**: 病人 / 模态 / 尺寸 / 切片 / 体素值 / WW-WL；状态栏在最底部

### 视图交互（重要）

| 操作 | 预期效果 |
|------|---------|
| 滚轮向上/向下 | 当前视图**翻层**（只影响当前视图，其他视图不动） |
| **Ctrl + 滚轮** | **放大 / 缩小**（以视图中心为焦点；平行投影无畸变） |
| **中键拖动** | **平移**图像（内容跟随光标） |
| 视图左上角 `↺` 复位 | 该视图缩放/平移复位（3D 视图为复位视角） |
| 鼠标移动（悬停） | 底部信息区**实时**显示「位置: 层… y=… x=…」和「体素值」（无需点击） |
| 左键**单击** | 设置种子点：状态栏「拾取点: 层x, y=…, x=…」 |
| 左键**拖动** | **无任何效果**（调窗已彻底禁用，勿以为坏了） |
| **Shift + 移动鼠标** | 十字联动：以鼠标处 3D 点为心，**其余两视图实时跳层**；状态栏显示定位点 + **RAS 坐标** |
| 左上角 `✛` 十字准星（开关） | 三个切片视图显示**琥珀色十字线**标记定位点投影 |
| 左上角 `▦` 切片平面（开关） | 3D 视图显示三个正交切平面（带 CT 纹理），随翻层实时移动 |
| 3D 视图 `前/后/右/左/上/下` | 切换标准视角（对应方向标记 R/L/A/P/S/I） |
| 「显示」页 WW/WL 旋钮 | 实时调整窗宽窗位（可先试 WW=400/WL=40 看软组织） |

> 说明: 十字联动与「十字准星」独立——Shift+移动始终有效；十字线由 `✛` 开关控制。

## 三、图像增强（右侧「增强」页）

**通用流程**：选方法 → 设参数 → 点「**应用增强**」→ 观察 → 点「**恢复原图**」回到原始状态。

**增强后 WW/WL 行为**：
- **归一化类**（线性/对数/伽马/直方图均衡/CLAHE）：数据变为 [0,255]，WW/WL 自动变约 **255/128**
- **滤波类**（均值/中值/高斯/锐化）：保持 HU 语义，WW/WL **沿用原始值 3445/698**

| # | 方法 | 测试参数 | 预期效果 |
|---|------|---------|---------|
| 1 | 线性拉伸 | （无参数） | 软组织**明显变亮、层次更分明**（2%~98% 百分位截断）；WW/WL→255/128 |
| 2 | 对数变换 | （无参数） | 暗部放大：**背景（空气）出现灰色噪声**、亮部压缩——属正常算法特性 |
| 3 | 伽马变换 | γ=**0.4** | 明显**提亮** |
| 4 | 伽马变换 | γ=**2.0** | 明显**压暗** |
| 5 | 直方图均衡 | （无参数） | 对比度增强，但**背景出现灰色噪声**（CT 空气占比大的固有现象） |
| 6 | CLAHE | clip_limit=**0.02** | **局部**对比增强，软组织细节更清晰、背景较干净（推荐；240 层需数秒） |
| 7 | 均值滤波 | 核大小 **3** | 平滑/模糊、去噪；WW/WL 保持 3445/698 |
| 8 | 中值滤波 | 核大小 **3** | 平滑去噪、边缘保留好于均值（较慢，数秒） |
| 9 | 高斯滤波 | σ=**1.0** | 柔和模糊 |
| 10 | 锐化 | 锐化量 **1.0** | 边缘**变锐利**（边缘可能有轻微过冲亮边，正常） |

**要点**：
- 每步之后点「恢复原图」，图像应完全回到原始状态
- 处理大卷时状态栏显示「增强处理中...」+ 等待光标，属正常
- 分割结果在增强后仍会正常叠加（叠加基于原始体数据，尺寸一致）

## 四、图像分割（右侧「分割」页）

分割**基于原始 CT（HU）数据**计算，与当前显示是否增强无关；结果显示为**红色半透明叠加**，三视图同步。

### 1. 阈值分割
1. 选「阈值分割」，阈值 **40** → 应用分割
2. 预期：红色覆盖**软组织**（腹部器官）；状态栏「分割完成 | 与胰腺真值 Dice=…」
3. 阈值改 **200** → 再应用：红色只剩**骨骼**（脊柱/肋骨）等高密度组织

### 2. Otsu 自动阈值
1. 选「Otsu 自动阈值」→ 应用分割
2. 预期：自动阈值约 **-492 HU**，红色覆盖**身体轮廓**（排除空气）；状态栏显示 Otsu 阈值与 Dice

### 3. 区域生长
1. 选「区域生长」
2. 在 Axial 视图滚轮翻到腹部中间层，在胰腺区域**左键单击**
3. 预期：状态栏「拾取点: 层x, y=…, x=…」，信息区「体素值」出现数字（如 94.0）
4. 容差 **10** → 应用分割：红色从种子点长出**小区域**
5. 容差 **50** → 再应用：红色**大面积漫溢**

### 4. 清除分割
- 点「清除分割」→ 红色叠加消失

**要点**：
- 不点种子直接区域生长 → 弹窗提示「请先在切片视图上点击, 设置种子点后再应用」
- Dice 仅在有 SEG 序列时显示；容差小/种子准 → Dice 高，容差大 → 漫溢 → Dice 低
- 增强后分割结果叠加仍对齐（分割在原始数据上算，叠加按同一坐标显示）

## 五、三维重建（右侧「三维重建」页）

**通用流程**：选方式 → 设参数 → 点「**应用重建**」→ 3D 视图出现模型（可左键旋转/滚轮缩放）→「清除重建」移除。

### 1. 面绘制（Marching Cubes）
1. 方式选「面绘制」，点预设 **骨**(300) → 应用重建
2. 预期：3D 视图出现**骨骼**等值面模型（脊柱/肋骨）
3. 依次试预设 **软组织**(40)、**皮肤**(-150) → 模型范围变化
4. 数据树切到 **SEG 序列** 再重建（预设 **掩膜** 0.5）→ 出现**胰腺 3D 表面**（很直观）

### 2. 体绘制（Ray Casting）
1. 方式选「体绘制」，不透明度 **0.5** → 应用重建
2. 预期：3D 视图出现**半透明体渲染**（软组织层次，光线投射）
3. 不透明度调 **0.2** / **0.9** 再应用 → 透明度变化

**要点**：
- 重建基于**当前序列**（可对增强后数据或 SEG 掩膜重建）
- 3D 视图交互：左键旋转、滚轮缩放、中键平移（与切片视图无关）
- **3D 视角切换**（菜单/工具栏「3D 视角」）：**复位视角** + 前/后/右/左/上/下（对应方向标记 R/L/A/P/S/I）
- **切片平面 (3D)**（菜单/工具栏开关）：3D 视图显示三个正交切平面（带 CT 图像纹理、半透明），**随切片翻层/十字联动实时移动**——直观看到 2D 切片在 3D 中的位置
- 重建期间状态栏「三维重建处理中...」+ 等待光标
- 重建较大（骨约 50 万顶点、软组织约 355 万顶点）可能需要几秒

## 六、正常 vs 异常对照

**正常表现**：
- 每次操作后状态栏有反馈（增强完成 / 分割完成 / 拾取点 / 已恢复 / 已清除 / 已开启十字准星 / 重建完成）
- 左键拖动**无效果**（切片视图已禁用调窗，属正常）
- 分割叠加随翻层跟随，三个视图同步
- 3D 视图：**未重建时是蓝色线框**，重建后显示模型（均正常）
- 启动时**不再弹出** vtk 错误窗口

**异常（出现任一需报告）**：
- 应用增强/分割/重建后无变化且状态栏无提示
- 控制台出现 Traceback
- 界面卡死
- 红色叠加与图像错位
- 十字联动跳层方向错误或不动
- 体绘制黑屏/空白（可能 GPU 兼容问题，需反馈）
