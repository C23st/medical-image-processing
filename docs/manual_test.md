# 手动测试指南: 图像增强 (P3) + 图像分割 (P4)

> 适用版本: master `4b87ad8` 之后

## 0. 准备

1. 启动: 双击 `run.bat`（或 `D:\Anaconda_Envs\medimg\python.exe main.py`）
2. 菜单「文件 → 打开 DICOM 文件夹」→ 选 `test_data\PANCREAS_0001`
3. 左侧数据树出现 2 个序列（CT + SEG），双击「序列: Pancreas」加载 CT
4. 三个切片视图显示腹部 CT，滚轮翻层只变层数、不缩放

---

## 一、图像增强（右侧「增强」页）

**通用流程**：选方法 → 设参数 → 点「**应用增强**」→ 观察三个切片 → 点「**恢复原图**」回到原始状态。

| # | 方法 | 参数建议 | 预期结果 |
|---|------|---------|---------|
| 1 | 线性拉伸 | 无 | **软组织更亮、层次更分明**（2%~98% 百分位截断拉伸；默认窗位已覆盖全范围时纯 min-max 拉伸视觉无变化） |
| 2 | 对数变换 | 无 | 暗部细节增强、整体偏亮、动态范围压缩 |
| 3 | 伽马变换 | γ = **0.4** | 明显**提亮**暗部 |
| 4 | 伽马变换 | γ = **2.0** | 明显**压暗** |
| 5 | 直方图均衡 | 无 | 对比度增强、组织层次更分明 |
| 6 | CLAHE | clip_limit = 0.02 | 局部对比度增强、细节更清晰（240 层全卷需数秒） |
| 7 | 均值滤波 | 核大小 3 | 图像**平滑/模糊**，噪声减少 |
| 8 | 中值滤波 | 核大小 3 | 平滑去噪，边缘保留好于均值（较慢，数秒） |
| 9 | 高斯滤波 | σ = 1.0 | 柔和模糊 |
| 10 | 锐化 | 锐化量 1.0 | 边缘**变锐利**、更清晰 |

**要点**：
- 归一化类（1–6）增强后窗宽窗位自动变约 255/128；滤波类（7–10）保持 HU 范围，窗宽窗位≈原值（约 3445/698）
- 每步之后点「恢复原图」，图像应完全回到原始状态
- 处理大卷时状态栏显示「增强处理中...」+ 等待光标，属正常

## 二、图像分割（右侧「分割」页）

分割基于**原始 CT**计算；结果显示为**红色半透明叠加**，在三个切片视图同步显示。

### 1. 阈值分割
1. 选「阈值分割」，阈值设 **40** → 点「应用分割」
2. 预期：红色覆盖**软组织**（腹部器官区域）；状态栏「分割完成 | 与胰腺真值 Dice=…」
3. 阈值改 **200** → 再应用：红色只覆盖**骨骼**（脊柱/肋骨等）等高密度组织

### 2. Otsu 自动阈值
1. 选「Otsu 自动阈值」→ 点「应用分割」
2. 预期：自动阈值约 **-492 HU**，红色覆盖**身体轮廓**（排除空气背景）；状态栏显示 Otsu 阈值与 Dice

### 3. 区域生长
1. 选「区域生长」
2. 在 Axial 视图**滚轮翻到腹部中间层**，在胰腺区域**左键点击**
3. 预期：状态栏「拾取点: 层x, y=…, x=…」，信息区「体素值」出现数字（如 94.0）
4. 容差设 **10** → 应用分割：红色从种子点生长出**小区域**
5. 容差设 **50** → 再应用：红色**大面积漫溢**（容差越大长得越多）

### 4. 清除分割
- 点「清除分割」→ 红色叠加消失

**要点**：
- 不点种子点直接区域生长 → 弹窗提示「请先在切片视图上点击, 设置种子点后再应用」
- Dice 数值说明：容差小/种子好 → Dice 高；容差大 → 漫溢 → Dice 低。Dice 与真值对比仅在有 SEG 序列时显示

## 三、正常 vs 异常对照

**正常表现**：
- 每次操作后底部状态栏有反馈（增强完成 / 分割完成 / 拾取点 / 已恢复原图 / 已清除分割结果）
- 分割结果三个切片视图都有红色叠加，翻层后叠加跟随当前层
- 3D 视图仍是蓝色线框（P5 三维重建未实现，属正常）

**异常（出现任一需报告）**：
- 点「应用增强/应用分割」后无任何变化且状态栏无提示
- 控制台窗口出现 Traceback 报错
- 界面卡死或崩溃
- 红色叠加与图像错位
